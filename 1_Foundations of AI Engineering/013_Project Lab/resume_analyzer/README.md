# Resume Analyzer

- upload the resume
- extract information
    - name
    - email
    - number
    - skills
    - education
    - work experience
- resume scoring


Use cases
- recruiter automation
- career counseling
- job matching

## steps

1. environment
2. download english model from spacy
3. create project files and folders
4. pdf extraction
5. nlp logic - resume analyzer
6. flask app
7. frontend templates
8. run the project
